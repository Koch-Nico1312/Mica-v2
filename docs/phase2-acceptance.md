# Phase-2-Abnahme

## Automatisch geprüft

- [x] Zwei feste Lerndomänen mit getrennten Quellen-Allowlists.
- [x] Netzwerk und Monitoring sind standardmäßig deaktiviert.
- [x] HTTPS-, Host-, DNS/IP-, Redirect-, MIME- und Größenprüfung vorhanden.
- [x] Recherche speichert zitierte Markdown-Zusammenfassungen mit Frontmatter.
- [x] Brain-Suche kann nach Domäne und Dokumenttyp filtern.
- [x] Text und Voice verwenden denselben eindeutigen Recherchebefehl.
- [x] PWA zeigt Domänen, Fortschritt, Wissen und Review-Entwürfe.
- [x] Monitoring ist endlich, dedupliziert Inhalte und bleibt separat gegatet.
- [x] Phase-2-Unit-/API-Tests und relevante Phase-0/1-Regressionen laufen.

## Noch manuell abzunehmen

- [ ] Je eine echte Recherche in `it-programmierung` und `server-homelab`.
- [ ] Jede Kernaussage gegen die angegebene Originalquelle prüfen.
- [ ] Neustart durchführen und gespeichertes Wissen erneut finden.
- [ ] Mit `MICA_LEARNING_NETWORK=0` einen Recherchebefehl ablehnen lassen.
- [ ] Mehrere Tage manuelle Recherche zuverlässig im Alltag verwenden.
- [ ] Erst danach Monitoring aktivieren und Draft/Review einmal vollständig testen.
- [ ] Offene physische und mehrtägige Phase-0/1-Abnahmen abschließen.

Phase 2 gilt bis dahin als technisch vorbereitet, nicht als vollständig im
Alltag abgenommen.
