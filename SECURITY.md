# Security Policy

## Unterstützte Versionen

Für die folgenden Versionen des Projekts werden derzeit Sicherheitsupdates bereitgestellt:

| Version | Unterstützt |
| ------- | ----------- |
| 0.5.0   | ✅           |

Es wird empfohlen, immer eine unterstützte Version zu verwenden. Für nicht mehr unterstützte Versionen werden keine Sicherheitsupdates oder Fehlerbehebungen garantiert.

## Sicherheitslücke melden

Wenn du eine Sicherheitslücke oder ein mögliches Sicherheitsproblem entdeckst, melde es bitte nicht öffentlich über ein Issue.

Du kannst mich über Instagram erreichen:

**Instagram:** https://www.instagram.com/nico_k1307/

Bitte gib bei deiner Meldung möglichst folgende Informationen an:

- Eine genaue Beschreibung der Sicherheitslücke
- Die betroffene Version des Projekts
- Schritte, mit denen sich das Problem reproduzieren lässt
- Mögliche Auswirkungen der Sicherheitslücke
- Screenshots, Fehlermeldungen oder Beispielcode, falls vorhanden
- Einen möglichen Lösungsvorschlag, falls bekannt

## Bearbeitung der Meldung

Nach Eingang einer Meldung kannst du mit folgendem Ablauf rechnen:

1. Der Eingang der Meldung wird normalerweise innerhalb von **7 Tagen** bestätigt.
2. Die Sicherheitslücke wird anschließend geprüft und bewertet.
3. Du erhältst regelmäßig eine Rückmeldung zum aktuellen Stand.
4. Wenn die Sicherheitslücke bestätigt wird, wird eine Lösung vorbereitet und als Sicherheitsupdate veröffentlicht.
5. Falls die Meldung abgelehnt wird, erhältst du nach Möglichkeit eine Begründung.

Bitte veröffentliche keine Details zur Sicherheitslücke, bevor eine Lösung verfügbar ist. Dadurch werden Nutzerinnen und Nutzer geschützt, die noch eine betroffene Version verwenden.

Vielen Dank, dass du dabei hilfst, dieses Projekt sicher zu halten.
